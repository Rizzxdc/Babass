# Bot Control (APK)
WebView ke dashboard (app/src/main/assets/index.html) yang memanggil API bot.

## Build lewat GitHub
1. Buat repo baru di GitHub (boleh private), upload SEMUA isi folder ini (termasuk folder .github).
2. Buka tab Actions -> Build APK -> Run workflow (atau otomatis saat push).
3. Setelah hijau, buka run-nya -> Artifacts -> BotControl-apk -> download, ekstrak, install APK.
   (Izinkan "Install dari sumber tidak dikenal" di HP.)

## Pakai
Isi alamat server (mis. 163.52.135.142:3199) dan token API, lalu Masuk.
Alamat + token tersimpan di HP.
